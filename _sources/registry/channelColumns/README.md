# `channelColumns/` -- ADA Channel Column Specification Registry

43 defs.

One `$def` per **column of a channel table**. A channel is an instrument *selection position* -- a
mass, a Faraday cup, an energy-loss edge, an X-ray line. It is not a flavour of analyte: the analyte
is what is measured, the channel is the position it is measured on, and the two are independent.

A procedure-side column is always a `schema:PropertyValueSpecification`, however tightly the
procedure fixes it -- read-only is an attribute of the specification (`schema:readonlyValue`), not a
different kind of thing. The `schema:PropertyValue` form is used on the **$Dataset** side alone,
where the member is not a column definition but the value the analysis recorded. (The base
`KeyedTableColumn` requires the specification form, so emitting the value form on the procedure side
produced a constraint no instance could satisfy.)

A dual-homed column defines two shapes under one name, so the dataset-side def takes an
`AnalysisValue` suffix and the two do not overwrite each other in this shared file.

## Generated by

`tools/schema_path_emitter.py`, via `tools/build_pathdriven.py`, from rows whose schema path ends at
`ada:channelTemplate.ada:channelColumns[]`.


## How these are used

The `$defs` here are **inlined into each technique's generated schema, not `$ref`d** -- nothing in
`_sources/` points a `$ref` at this file. The building block is declared `isTypeLibrary: true`: a
shared catalogue you can read, diff and publish, while the copy a validator actually enforces lives
in the technique that uses it.

Keys are namespaced by TAPP prefix (`empa_acceleratingVoltage`), because these are shared across all
16 techniques and a bare name collides -- `detectionLimit` is generated by seven of them. The `@id`
const inside a def carries the same identity, so a def is unambiguous however it is keyed.

## Do not hand-edit

Every file here is generated. Fix the source -- the technique's `docs/*.schemapaths.csv` sidecar, the
table in the `tapp/` submodule, or the generator -- and re-run. A hand edit is overwritten by the
next regeneration, silently.

See `../README.md` for the two generator routes and how they can disagree.
