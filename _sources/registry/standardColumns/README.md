# `standardColumns/` -- ADA Standard Column Specification Registry

One `$def` per **column of a standards table** -- the fifth keyed domain, alongside target species,
target materials, monitored properties and reported properties.

A standard STANDARDIZES something, so a row of this table is a standard BY its standardization
target: one natural kaersutite standard calibrating Si, Fe and Mg is three rows, which is why the
TAPP workbooks key these items as the cross-product `standard x reported property` and why the
identifier column is deliberately not unique per row.

Shape taken from the Standards worksheet of `metadata/EPMA-templates20261031.xlsx`: the standard's
type and material, what it standardizes, which target materials it applies to, the citation for its
accepted values, and the expected analytical precision and accuracy for that standard-target pair.

The standard ITSELF is a `bios:reagent` (`tappDefinition#/$defs/Reagent`), which owns the
material's identity, its `ada:reagentRole` and the `schema:citation` for its accepted values. A
record references that entity; these columns describe the table, not a second home for the
material.

Generated by `tools/build_pathdriven.py` from the schema-path sidecars. Do not hand-edit.
