# Lab-XCT Analysis Detail

Analysis-level detail block for Laboratory X-ray computed tomography (Lab-XCT) `hasPart` items.

Discriminates on `ada:componentType` (a string: `ada:XCTVolume`, `ada:XCTProjectionImageSet`,
`ada:XCTSegmentationVolume`, `ada:XCTRenderedImage`, `ada:XCTQuantitativeTabular`), references a
registered [labxctTAPP](../../techniqueProtocols/labxctTAPP/) definition via
`schema:measurementTechnique` (`@id`), and carries the analysis-level required properties
(`ada:analyst`, `ada:analysisStartDate`/`EndDate`, `ada:protocolDoi`, `ada:sampleName`,
`ada:sampleDimensions`, `ada:voiApplied`, `ada:fundingSourceForAnalysis`).

Per-dataset values are recorded as `schema:additionalProperty[]` `schema:PropertyValue` entries,
constrained inline via `$ref`s to the [parameterValues](../../techniqueProtocols/parameterValues/)
registry — one branch per session-editable labxctTAPP parameter, plus a catch-all. All
`schema:additionalProperty` entries are optional; include only the parameters you have values for.

Multi-volume-stitching-only fields (`ada:numberOfSubVolumes`, `ada:subVolumeOverlap`) are present but
not globally required, so single-volume datasets validate without them.

Generated by `tools/build_labxct_from_spreadsheet.py` from `docs/Lab-XCT_TAPP_v8.xlsx`.
