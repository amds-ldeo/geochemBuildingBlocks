# LA-ICPMS Analysis Detail

Analysis-level detail block for Laser Ablation ICP-MS (`detailLAICPMS`) `hasPart` items.

Discriminates on `ada:componentType` (`ada:LAICPMSTabular`, `ada:LAICPMSMap`, `ada:LAICPMSImage`,
`ada:LAICPMSTransect`), references a registered [laicpmsTAPP](../../techniqueProtocols/laicpmsTAPP/)
definition via `schema:measurementTechnique` (`@id`), and carries the analysis-level required
properties (analyst, analysis dates, sample name/identifier, number of replicates, spot coordinates,
transect length, mapping area, etc.).

Per-dataset values are recorded as `schema:additionalProperty[]` `schema:PropertyValue` entries,
constrained inline via `$ref`s to the
[parameterValues](../../techniqueProtocols/parameterValues/) registry — one branch per
session-editable laicpmsTAPP parameter, plus a catch-all. All `schema:additionalProperty` entries
are optional.

Generated by `tools/build_laicpms_from_spreadsheet.py` from `docs/LA-Q_SF-ICPMS_TAPP_v2.xlsx`.
