## Description

# TAPP Composition Module: Geochronology

The shared **Geochronology** block of the 2026-08-11 TAPP library, composed by **3 of the sixteen** delivery tables — 6 owned fields over 16 schema paths.

Generated by `tools/build_module_bb.py` from `Module_Geochronology.csv` and its schema-path sidecar. Edit those, not the schema.

This is a **profile, not a vocabulary**: it asserts which properties a conforming procedure or analysis carries, all of them already defined by `tappDefinition` or `adaProduct`.

## The two `$defs`

| `$def` | composed into | properties | required |
|---|---|---|---|
| `ProcedureIdentification` | a TAPP schema (`prov:Plan`) | 5 | 2 |
| `AnalysisIdentification` | a technique detail (`schema:Dataset`) | 2 | 0 |

Requiredness follows the TAPP tier matrix: a field Basic on a side is required there, Advanced is permitted, N/A is absent from that side entirely.

allOf:

`allOf` composes constraints and cannot relax them: a technique composing this module accepts its required set in full.
