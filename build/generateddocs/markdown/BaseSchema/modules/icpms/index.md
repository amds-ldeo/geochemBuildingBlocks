## Description

# TAPP Composition Module: ICPMS

The shared **ICPMS** block of the 2026-08-11 TAPP library, composed by **9 of the sixteen** delivery tables — 39 owned fields over 17 schema paths.

Generated by `tools/build_module_bb.py` from `Module_ICPMS.csv` and its schema-path sidecar. Edit those, not the schema.

This is a **profile, not a vocabulary**: it asserts which properties a conforming procedure or analysis carries, all of them already defined by `tappDefinition` or `adaProduct`.

## The two `$defs`

| `$def` | composed into | properties | required |
|---|---|---|---|
| `ProcedureIdentification` | a TAPP schema (`prov:Plan`) | 10 | 8 |
| `AnalysisIdentification` | a technique detail (`schema:Dataset`) | 4 | 0 |

Requiredness follows the TAPP tier matrix: a field Basic on a side is required there, Advanced is permitted, N/A is absent from that side entirely.

## Not yet placed

These fields belong to the module but have no schema path in any sidecar, so they are absent from the schema until one is authored:

- Instrument Sensitivity
- Ion Counter Dead Time
- Internal (Within-Measurement) Analytical Precision and Assessment Method
- Within-Session Analytical Precision and Assessment Method
- Between-Session (Long-Term) Analytical Precision and Assessment Method
- Analytical Accuracy and Assessment Method
- Limit of Quantification (LOQ) Method
- Per-Analyte Calibration Strategy
- Interference Correction Method
- Interference Correction Method
- Interfering Species
- Interfering Species
- Spectral Interference Corrections Applied

## Composing it

```yaml
allOf:
- $ref: ../../../BaseSchema/tappDefinition/schema.yaml
- $ref: ../../../BaseSchema/modules/icpms/schema.yaml#/$defs/ProcedureIdentification
```

`allOf` composes constraints and cannot relax them: a technique composing this module accepts its required set in full.
