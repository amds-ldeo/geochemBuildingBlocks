## Description

# TAPP Composition Module: Analyte

The shared **Analyte** block of the 2026-08-11 TAPP library, composed by **13 of the sixteen** delivery tables — 1 owned fields over 1 schema paths.

Generated by `tools/build_module_bb.py` from `Module_Analyte.csv` and its schema-path sidecar. Edit those, not the schema.

This is a **profile, not a vocabulary**: it asserts which properties a conforming procedure or analysis carries, all of them already defined by `tappDefinition` or `adaProduct`.

## The two `$defs`

| `$def` | composed into | properties | required |
|---|---|---|---|
| `ProcedureIdentification` | a TAPP schema (`prov:Plan`) | 1 | 0 |

Requiredness follows the TAPP tier matrix: a field Basic on a side is required there, Advanced is permitted, N/A is absent from that side entirely.
