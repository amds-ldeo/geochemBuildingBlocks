# TAPP Composition Module: Blank

The shared **Blank** block of the 2026-08-11 TAPP library, composed by **12 of the sixteen** delivery tables — 1 owned fields over 0 schema paths.

Generated by `tools/build_module_bb.py` from `Module_Blank.csv` and its schema-path sidecar. Edit those, not the schema.

This is a **profile, not a vocabulary**: it asserts which properties a conforming procedure or analysis carries, all of them already defined by `tappDefinition` or `adaProduct`.
